Usage: sportstradamus admin backfill-nhl-gamelog [OPTIONS]

  Fill the NHL gamelog rows that lack the season-sum columns, or the report
  columns.

Options:
  --season INTEGER  Restrict to these season start years, e.g. 2025.
  --reports         Fill the stats-service report columns instead; re-parses no
                    game.
  --help            Show this message and exit.
