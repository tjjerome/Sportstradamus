Usage: sportstradamus fetch fp [OPTIONS] COMMAND [ARGS]...

  Snapshot Fantasy Points Data Suite tools to disk.

Options:
  --help  Show this message and exit.

Commands:
  backfill      Iterate (season, week) pairs and write per-tool parquets...
  discover      Auto-populate the catalog from Fantasy Points' tool registry.
  import-curl   Register a new endpoint from a DevTools-copied curl command.
  list          Print the registered endpoint catalog.
  refresh-auth  Update auth fields in creds/keys.json from a fresh curl...
  run           Walk the catalog, fetch every endpoint, write one parquet...
  verify        Spot-check downloaded parquets against the requested season...
