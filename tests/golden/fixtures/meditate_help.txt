Usage: meditate [OPTIONS]

  Train or retrain LightGBMLSS models for each configured market.

Options:
  --force / --no-force            Skip markets with fresh data (default). Pass
                                  --force to rebuild the prior correlation CSV
                                  cache and build markets whose models are
                                  already up to date.
  --league [All|NFL|NBA|MLB|NHL|WNBA]
                                  Select league to train on
  --rebuild-filter / --no-rebuild-filter
                                  Train with full feature set (ignore Filtered),
                                  then rerun SHAP and rewrite filter
  --reset-markets TEXT            Comma-separated league:market pairs (or just
                                  market for active league) to clear from
                                  Filtered before training
  --rebuild-correlations / --no-rebuild-correlations
                                  Rebuild only the per-league correlation
                                  matrices and exit; skip the per-market
                                  training loop
  --log-level [DEBUG|INFO|WARNING|ERROR]
                                  Verbosity for the structured JSONL log.
  --deterministic / --no-deterministic
                                  DEBUG/EVAL ONLY: pin all RNGs, use fixed fast
                                  hyperparameters, and freeze input to the
                                  cached parquet so runs are bit-identical for
                                  the compression eval harness. NEVER publish a
                                  model trained with this flag — it is
                                  deliberately low quality.
  --help                          Show this message and exit.
