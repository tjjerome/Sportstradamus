Usage: sportstradamus admin tail-scorecard [OPTIONS]

  Replay the live recommendation rule on held-out test rows at the ladder's DFS
  rungs.

  A training-time diagnostic, never a ship gate. Prints the selected-tail gap
  per cell, league and overall beside the live gap over the same window, then
  the information test, and writes every scope and split to OUT.

Options:
  --league TEXT   Score only these leagues (repeatable). Default: every test
                  set.
  --archive FILE  Odds archive, opened read-only (default:
                  $SPORTSTRADAMUS_ARCHIVE_DB or archive/archive.duckdb).
  --out FILE      Sandbox CSV of every scope and split; never
                  model_stats.parquet.  [default: /tmp/tail_scorecard.csv]
  --help          Show this message and exit.
