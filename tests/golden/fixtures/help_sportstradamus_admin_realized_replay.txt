Usage: sportstradamus admin realized-replay [OPTIONS]

  Replay the live rule on held-out rows at posted rungs and market lines; read
  it against live.

Options:
  --league TEXT                Replay only these leagues (repeatable).
  --test-sets-dir PATH         Directory of {LEAGUE}_{market}.csv dumps
                               (default: the package's data/test_sets).
  --models-dir DIRECTORY       The dumps' own pickles, which price the posted
                               scope (default: the package's data/models; a
                               sandbox run's models beside its dumps).
  --archive FILE               Odds archive whose ladder prices the posted
                               scope, opened read-only (default:
                               $SPORTSTRADAMUS_ARCHIVE_DB or
                               archive/archive.duckdb).
  --offline-before [%Y-%m-%d]  Test rows dated before this are the cell, league
                               and l2 scopes' offline sample.  [default:
                               2026-10-09]
  --live-since [%Y-%m-%d]      Live legs, and the posted scope's offline legs,
                               dated from this day count (count-once holds from
                               COUNT_ONCE_FROM).  [default: 2026-10-09]
  --live-until [%Y-%m-%d]      Live legs, and the posted scope's offline legs,
                               dated before this day count (default: every
                               settled leg).
  --out PATH                   [default: /tmp/realized_replay.csv]
  --parquet PATH               Where the scope rows land (default:
                               data/training/realized_replay.parquet).
  --help                       Show this message and exit.
