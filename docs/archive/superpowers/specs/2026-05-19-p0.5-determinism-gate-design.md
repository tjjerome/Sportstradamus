# P0.5 — Deterministic Eval Mode + Determinism Gate (design)

**Date:** 2026-05-19
**Project:** GBDT mean-regression mitigation (`docs/gbdt_mean_regression_plan.md`)
**Branch / PR:** `claude/fix-gbdt-mean-regression-GcY1g` → PR #46 (all phases on
this one PR).

## Why

The overconfidence investigation (`docs/OVERCONFIDENCE_INVESTIGATION.md`)
established that offline evaluation of this training pipeline is
non-reproducible: the same nominal SkewNormal configuration produced
top-volume-quintile bias of −0.48, −0.92, −1.3, −2.0, −2.5, **and +0.12**
across runs. The P0 compression harness scores the CSVs `meditate` dumps, but
`meditate` itself is the non-deterministic stage, so its ship/kill verdict is
currently noise. **No P1+ target/baseline strategy can be validated until a
"run twice → bit-identical predictions" gate exists.** P0.5 builds that gate
and the opt-in deterministic mode it asserts on.

Confirmed non-determinism sources in `src/sportstradamus/training/pipeline.py`:

- `model.hyper_opt(...)` — Optuna study with no sampler seed and a
  `max_minutes` time-box (load-dependent trial count; the investigation's
  "Optuna starvation").
- `hp_search_space` enables `bagging_fraction` / `feature_fraction` < 1.0 but
  pins no LightGBM `seed` / `bagging_seed` / `feature_fraction_seed` /
  `deterministic`.
- `set_model_start_values` re-invoked before every predict (per-row broadcast).
- SkewNormal is a custom PyTorch distribution (`skew_normal.py`), so the torch
  RNG is in play.
- The temporal train/test split and the `random_state=25` validation split
  (pipeline.py:236) are **already** deterministic — not sources.

## Scope (locked with user)

- **Opt-in only.** A `--deterministic` flag on `meditate`, default off.
  Default production behavior stays byte-for-byte unchanged (project guardrail:
  never regress `devel`-tracking production mid-project).
- **Debugging only.** The flag is for offline reproducibility/evaluation. A
  model trained with `--deterministic` uses crippled fixed hyperparameters and
  frozen input and **must never be published as a production model.** This
  constraint is stated explicitly in the CLI help text and the `train_market`
  docstring.
- **Gate**: fixed params, skip Optuna, run the training core twice on real
  cached data, assert the **test-split predicted distribution parameters** are
  exactly equal.
- Real local data only (`src/sportstradamus/data/training_data/*.parquet`);
  no network.

## Architecture — five small units

### 1. `seed_everything(seed: int) -> dict`
New helper in `pipeline.py`. Seeds `random`, `numpy`, and `torch`; calls
`torch.use_deterministic_algorithms(True)` (CPU-only env, no cuBLAS env var
needed). Returns the LightGBM determinism kwargs to merge into train params:
`seed`, `bagging_seed`, `feature_fraction_seed`, `deterministic=True`,
`force_row_wise=True`. Single responsibility; unit-testable without training.

### 2. `DETERMINISTIC_FIXED_PARAMS` — module-level constant
A pinned LightGBM hyperparameter dict including `opt_rounds`, deliberately
small/fast (low `num_leaves`, capped `opt_rounds`). It only has to prove
*reproducibility*, not produce a good model — this is also why a
`--deterministic` model is non-production. Named constant with a one-line
reason comment (CLAUDE.md §8 / STYLE_GUIDE §8).

### 3. `_fit_test_params(...) -> pd.DataFrame`
Extract the existing inline fit→predict block (~pipeline.py:327–410) into a
pure function:
`(dist_obj, dist, X_train, y_train, X_test, params, *, normalized,
shape_ceiling, seed) -> prob_params` for the test split. **No disk writes.**
Both `train_market` and the gate test call it. This boundary makes the gate
fast and side-effect-free and removes the train/predict-drift risk the parent
plan calls out (the forward fit and the predicted-params extraction can no
longer diverge between callers).

### 4. `deterministic` flag plumbing
- `cli.py`: add `--deterministic/--no-deterministic` (default `False`). Help
  text states: *debugging/eval reproducibility only — never publish a model
  trained with this flag.*
- `train_market` gains `deterministic: bool = False`; docstring carries the
  same non-production warning.
- When `True`: call `seed_everything`, use `DETERMINISTIC_FIXED_PARAMS`
  (skip `hyper_opt`), and **freeze input** — skip the incremental
  `stat_data.get_training_matrix` fetch so the run uses only the cached
  parquet (reproducible, no network).
- When `False`: every existing code path is unchanged.

### 5. Gate test — `tests/golden/test_determinism_gate.py`
Marked `-m integration` (no network; reads cached `NBA_FGA.parquet`). Loads
the cached parquet, builds `X`/`y` exactly as `train_market` does,
deterministically subsamples to a fixed N rows (speed — still real data, still
proves bitwise reproducibility), calls `_fit_test_params` **twice** with the
deterministic config, and asserts
`pd.testing.assert_frame_equal(p1, p2, check_exact=True)` (zero tolerance).

## Data flow

```
meditate --deterministic
  └─ train_market(deterministic=True)
       ├─ seed_everything(SEED) ─────────────► RNG pinned + LGB det. kwargs
       ├─ load cached parquet ONLY (no fetch) ► frozen input
       ├─ params = DETERMINISTIC_FIXED_PARAMS  (no Optuna)
       └─ _fit_test_params(...) ─────────────► test-split prob_params
                                                (gate asserts == across 2 runs)
```

## Out of scope (YAGNI)

- Seeding/“controlled Optuna” for real (non-fixed) eval runs — the gate uses
  fixed params per the locked decision; reproducible-Optuna can be a later
  follow-up if a strategy needs the real search reproducible.
- Asserting the dumped CSV or model pickle byte-equality (predicted params is
  the contract the harness consumes; pickles carry serialization noise).
- Touching default production training behavior.
