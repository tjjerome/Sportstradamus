# I6d book-leg levelling: pre-registration

Frozen on 2026-10-27, before the decode harness first runs. The owner's decision 3 on the I6d
design (live-gap-2 lane, 2026-10-27 14:00 CDT) froze the decode bars and asked for the rest of
the research brief's pre-registration (candidate order, reference choice, epoch rule) in a
committed file before the harness runs. This is that file. The rules come from the brief,
[`archive/researcher_i6d_book_leg_levelling.md`](../archive/researcher_i6d_book_leg_levelling.md)
§3A steps 1 to 3, §3C and §4. The design and its acceptance live in
[live-gap-2.md](live-gap-2.md) §5.

**Do not edit this file.** Changing any rule below is a new pre-registration and a full re-run
of the harness (brief §3C). Where the brief is silent or reads two ways, the rule chosen is
marked *Resolution*; every resolution was fixed before any block was fitted.

Implementation: `helpers/book_levelling.py` (read time) and `scripts/fit_book_decode.py` (the
harness, which writes `data/config/book_decode.json`).

## 1. Rows in scope

Every `odds` row whose book is not a DFS platform (`training_quotes.DFS_PLATFORM_BOOKS`:
Underdog, PrizePicks, ParlayPlay, Sleeper, Thrive), that is, every row the training reader
treats as sportsbook evidence. DFS rows pass through unchanged.

## 2. Layer

An observation exactly on the hour (minute, second and microsecond all zero) at 00, 01, 02 or
23 UTC is a stamp layer, named `HH:00`. Every other observation is a live poll.
*Resolution:* the stamp's day is not checked against `game_date`.

## 3. Producer class

- **`00:00`:** migrated. Every midnight row predates the WS1 writer
  (`add_observed_at_to_archive`, 2026-05-09, stamped every row then present at game-date
  midnight).
- **`01:00`, `02:00`, `23:00`:** native if and only if a ladder row exists with the same
  league, market, game date, entity, book, line and `observed_at`; otherwise migrated.
  *Resolution:* this row-level test is used everywhere. It agrees with the brief's per-block
  table wherever a block's ladder share is 0 or 1, and it is the brief's rule for straddling
  blocks.
- **Live poll:** native if and only if `observed_at` is at or after 2026-07-11 14:50:03 UTC;
  otherwise migrated. *Resolution:* the brief pins the WS1 deploy from each box's run_job
  `PULL` lines, but run_job logged no `PULL` line before ee5cd0f2 (2026-07-11), so the
  06-28 deploy cannot be dated. The boundary is production's first `PULL` line (prophecize,
  2026-07-11T14:50:03Z). From then every job ran devel HEAD, which carries the WS1 writer
  (377972ce). The dev box runs no `confer`, so live polls are production's. Polls between the
  WS1 commit (2026-06-29T01:24:06Z) and the boundary are tested as migrated rows; a native one
  passes at the stored candidate when it is level.

## 4. Blocks (migrated rows only)

- **Live epoch:** `00:00` rows and migrated live polls together, per (league, market, game
  month `YYYY-MM`). *Resolution:* epochs are not split at config changes, because the cv
  history is gitignored. A month that straddles a change fails its validation half and is
  demoted.
- **Backfill block:** migrated `01:00` and `02:00` rows per (league, market, layer, season).
  The season is the game date's year when its month is at or after the league's start month
  (NFL 8, NBA 9, NHL 9, MLB 1, WNBA 1), and the year before otherwise. *Resolution:* the
  producer run cannot be read from the archive (there is no fetch log and the stamps are
  synthetic), so the season stands in for it, as the brief's Step 1 implementation note does.
- **`23:00` rows are not levelled.** They fall after the training read cutoff (game date
  12:00 UTC), so native close rows serve only as a reference.

## 5. Reference and matching

- **Reference rows:** the native rows of one reference layer, minus rows whose
  same-observation, same-line ladder rung differs from `1 − under_prob` by more than .05, and
  minus rows reading exactly .5 (`|under_prob − .5| < 1e-9`). *Resolution:* the brief cleans
  only the close ("with its Class II rows removed"); the same cleaning is applied to both
  reference layers.
- **Reference layer per block:** native `01:00` when the block is testable against it (§6),
  otherwise native `23:00`. *Resolution:* "where one exists" is read per block.
- **Matching:** a migrated row matches a reference key (game date, entity, book, line), with
  the line exactly equal, and is compared with the mean reference `under_prob` of that key.
  Several migrated rows may match one key; each counts.

## 6. Split

Sort the block's distinct matched game dates. The first ⌈n/2⌉ dates form the fit half and the
rest the validation half. A block is testable if each half holds at least 30 matched rows.
*Resolution:* the halves are chronological by game date, so drift inside a block fails
validation instead of averaging out.

## 7. Candidates

Tried in this order; a family already tried is skipped.

1. **stored:** the stored `under_prob` as it is. No parameter; rows with a null `under_prob`
   do not count toward it.
2. **code history:** the family configured for the (league, market) on the block's reference
   date in the committed distribution config: `src/sportstradamus/data/stat_dist.json` (from
   2026-02-23), then `data/config/stat_dist.json` (2026-05-22), then the `dist` field of
   `data/config/stat_meta.json` (from 2026-05-23), taking the last commit on or before the
   date. The reference date is the epoch's first day for a live epoch, and 2026-06-17 (the day
   before ladder capture, 92f918ab) for a backfill block. A market absent from the config reads
   SkewNormal, the writer's fall-through (`7a624294:moneylines.py:490-494`). The family maps to
   the decode set: ZINB to NegBin, ZAGamma to Gamma; SkewNormal, NegBin, Poisson and Gamma map
   to themselves. Any other family, or a date before the first committed config, skips this
   candidate.
3. **SkewNormal**, 4. **NegBin**, 5. **Poisson**, 6. **Gamma**.

The decodes are the brief scripts' (a4), all ungated:

| family | call |
|---|---|
| SkewNormal | `get_odds(line, ev, "SkewNormal", cv=cv, step=0.5)` (symmetric, sigma = ev·cv) |
| NegBin | `get_odds(line, ev, "NegBin", cv=cv, r=1/cv, step=1)` |
| Poisson | `get_odds(line, ev, "Poisson", step=1)` |
| Gamma | `get_odds(line, ev, "Gamma", cv=cv, step=0.5)` |

*Resolution:* `r` is passed explicitly, because `get_odds` turns NegBin at cv = 1 with no `r`
into Poisson.

## 8. Fit

Each parametric candidate (SkewNormal, NegBin, Gamma) fits one parameter, log cv, by
`scipy.optimize.minimize_scalar(..., bounds=(-5, 1.5), method="bounded")` of the mean squared
difference between the decoded and the reference `under_prob` on the fit half. The fit uses at
most 6,000 fit-half rows, sampled with seed 1729. Stored and Poisson have no parameter.
*Resolution:* the brief scripts' objective and bounds (a4).

## 9. Acceptance

On every validation-half row:

- `|mean(decoded − reference)| ≤ .01` and `median |decoded − reference| ≤ .03` (owner,
  2026-10-27);
- for a parametric candidate, an interior parameter: log cv strictly inside (−4.999, 1.499).

The first candidate that passes is accepted. A testable block where none passes is demoted.

## 10. Untestable blocks

- **Backfill block:** inherits the verdict of the nearest tested season of the same (league,
  market, layer), the later season on a tie. A demoted source demotes, and so does having no
  tested season.
- **Live epoch:** demoted.

## 11. Read-time rules

- **Accepted or inherited block:** a migrated row's `under_prob` becomes the decode of its
  stored `ev` at its stored line (stored: kept as it is). The row stays `authentic`, and the
  cohort it joins carries `QuoteSource = book_redecoded`.
- **Not a price:** a migrated row in a demoted block, a row with no usable `ev` or line, or a
  stored-accepted row with a null `under_prob`. It leaves the direct cohort and is not
  ev-inverted either. A player-game left with no admissible row resolves like any unpriced row,
  as non-authentic.
- **Class II with a rung:** a native row whose same-observation, same-line ladder rung differs
  from `1 − under_prob` by more than .05 takes `1 − rung`. Its cohort carries
  `QuoteSource = book_ladder_repaired` unless a re-decoded row is also in it.
- **Class II without a rung:** a native row reading exactly .5 while the median `under_prob`
  of the other sportsbook rows on the same line exceeds .70 is dropped. *Resolution:* the
  median, over the rows the training reader returns for that player-game.
- **No verdict:** a migrated row whose block is absent from the table stays as stored. The
  harness writes a verdict for every archived block, so only test fixtures meet this rule.

## 12. Records

`scripts/fit_book_decode.py` writes every block's numbers to
`src/sportstradamus/data/config/book_decode.json`: rows, matched rows, the halves, the reference
layer, and each candidate's validation-half mean difference, median absolute difference and
parameter, with the verdict. The table is committed.

## 13. M1, the deciding read

Read once, after M0 and before any retrain, on the re-injected training matrices.

- **(i) NFL.** The lane script `e3/h3_t1.py` on the seven NFL count cells (attempts, carries,
  completions, interceptions, passing tds, receptions, tds), with three changes: the matrices
  are the re-injected cache; the row check is against the current `data/test_sets`; the live
  window is fixed at 2026-09-21 to 2026-10-19, the recorded run's. Pass: `L_off ≤ .03` and the
  95% CI of `D = L_off − L_live` includes 0.
- **(ii) Every served cell** (`shipped` not `withheld` at the read) with at least 100 authentic
  held-out rows, the held-out rows being those after the first 70% of the matrix sorted by
  `Date` (the pipeline's cut, both halves): `|mean(Odds − y)| ≤ .03`, where `Odds` is the
  matrix book P(over) and `y` is over with a push counted as ½. Exceptions are reported, not
  failed: MLB home runs, MLB stolen bases and NHL goals up to +.05; NFL carries, attempts and
  completions.
- **(iii) NHL band.** The served NHL cells pooled: current test-set rows (`P`), with the book
  P(over) taken from the re-injected matrix and joined on (Player, Date), authentic rows only.
  On the band `|P − p_book| > .10`, BSS = `1 − Σ Brier_model / Σ Brier_book`; its 95% lower
  bound is the .025 quantile of 4,000 game-date block draws with seed 1729 (as `e4/bands.py`
  computes it). Pass: the lower bound is below +.10.
- **(iv) Report only.** Spearman ρ between BSS and `|book CITL|` over the (ii) cells; per cell,
  BSS on re-decoded rows against native rows.

M1 passes when (i), (ii) and (iii) all pass; then each league retrains. If M1 fails while M0
passes, a mis-levelling class not found here remains: stop, retrain nothing on it, and diagnose
with the brief's `t2`, `a10` and `a11` scripts.

## 14. What never enters

No outcome enters §§1 to 12. No bar is retuned after M1, and M1 never chooses between
levelling variants.
